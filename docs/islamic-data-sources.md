# سياسة مصادر البيانات الإسلامية

هذا الملف يحدد ترتيب المصادر داخل مشروع **ذُو الجلال** حتى لا ترتبط الواجهة بمزوّد واحد فقط.

## القرآن والمصحف

- **صفحات المصحف الأساسية:** Al Furqan SVG — صفحات كاملة 1–604، بلا إعادة تركيب للأسطر داخل الواجهة.
- **احتياطي صفحة المصحف:** Islamic App SVG.
- **بيانات السور والآيات:** Islamic App أولًا، ثم AlQuran Cloud كـ fallback.
- **خط النص العثماني في بطاقات المشاركة:** Quran Foundation Uthmanic Hafs CDN.
- **التجويد:** Islamic App حاليًا.
- **ترقية مستقبلية عالية الأولوية:** Quran Foundation QCF V2 لعرض مطابق للمصحف وقابل للتفاعل، وQCF V4 لتجويد ملون. هذه الخطوة تحتاج بيانات glyph/page layout وتوثيق وصول مناسب من Quran Foundation؛ لا ينبغي محاكاة تنسيق الصفحة يدويًا.

### قاعدة تصميم ملزمة

صفحة المصحف هي **قارئ** وليست بطاقة تصميم. يجب عرض الصفحة كاملة من مصدر مصحف موثوق، بينما بطاقات الآيات منفصلة ومخصصة للمشاركة والحفظ. لا نعيد ترتيب أسطر المصحف أو نحقن بسملة أو نصًا قرآنيًا من الواجهة.

## مبادئ التنفيذ

1. لا يعرض التطبيق نصًا قرآنيًا بديلًا غير موثّق عند تعطل المصدر.
2. المصادر التي لا تحتاج مفتاحًا يمكن استخدامها كـ fallback، لكن لا تُعامل تلقائيًا كمصدر رسمي.
3. أي مصدر يحتاج أسرار OAuth/API يوضع خلف الخادم فقط ولا يُكشف للمتصفح.
4. البيانات القرآنية النصية لا تُعدّل؛ التطبيع المسموح يقتصر على ما لا يغيّر الحروف أو الرسم.
5. عند إضافة مزود جديد، يجب أن يحافظ على نفس domain types حتى يبقى تبديل المصادر شفافًا للواجهة.
