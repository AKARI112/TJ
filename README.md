# ذُو الجَلاَلْ

تطبيق إسلامي عربي أولًا يجمع القرآن والمصحف والتلاوات والصلاة والقبلة والأذكار والأدعية وحصن المسلم والحديث ومكتبة الكتب. يحافظ على النصوص الدينية كما يوردها مصدرها ولا يولّد آيات أو أحاديث أو درجات أو تفاسير.

## ما هو منفّذ فعليًا

- واجهة RTL أصلية بخط Fustat، داكنة جرافيت افتراضيًا مع وضعي الفاتح والنظام.
- beUI v2: Sidebar وBottom Sheet وMorphing Search وTabs وSelect وSwitch وInput ومكوّنات حركة منتقاة.
- القرآن في ثلاثة أوضاع: مصحف 604 صفحات، قراءة متجاوبة حسب السورة، وتجويد عثماني ملوّن.
- Islamic App هو المصدر الرئيسي المفتوح للقرآن: 114 سورة، ستة أنماط نصية، أكثر من 100 ترجمة، نحو 20 تفسيرًا، بيانات كلمة بكلمة، البحث، وصفحات المصحف SVG بثلاثة خطوط. لا يحتاج تسجيلًا أو مفتاح API.
- صفحات المصحف من Islamic App مع عثماني/إملائي/هندي باكستاني، سحب محمول، انتقال مباشر، وحفظ موضع القراءة في IndexedDB.
- التفسير والترجمة وword-by-word تُحمّل عند فتح أداة الآية، مع اسم المورد والمصدر. AlQuran Cloud احتياط دلالي لوضع القراءة والبحث فقط.
- Islamic App هو المصدر الرئيسي للأذكار والأدعية وحصن المسلم (132 بابًا). تبقى snapshots المحلية من Fitrahive وHisnElMuslim للاستخدام الاحتياطي دون اتصال.
- مكتبة Islamic App للكتب الإسلامية: كتالوج مصنف، بحث محلي في الكتب المحملة، صفحات كتاب، قراءة نص Turath/OpenITI، وبث PDF مع Range عبر المتصفح.
- دليل MP3Quran، اختيار السورة، صفحات القارئ، queue، مشغل عالمي، Media Session، السرعة والتكرار ومؤقت النوم.
- HadeethEnc للحديث والدرجة والشرح والفوائد والمراجع.
- AlAdhan للصلاة والقبلة، مع الموقع/المدينة وطريقة الحساب والمذهب والعد التنازلي المحلي.
- بحث عام يجمع القرآن والحديث والأذكار وحصن المسلم والكتب.
- محفوظات وسجل ومتابعة قراءة وتذكيرات وإعدادات، وShare Composer للحفظ كصورة.
- PWA مع manifest وoffline fallback وذاكرة shell والمحتوى المقروء، من دون تنزيل الصوت أو ملفات PDF تلقائيًا.

## التقنية

- Next.js App Router 16.3.3، React 19، TypeScript strict، Tailwind CSS 4
- Server Components افتراضيًا وClient Components للتفاعل وواجهات الجهاز فقط
- Zod عند جميع حدود API، Zustand للمشغل، IndexedDB للبيانات المحلية، وVitest للمنطق الحرج
- بنية متوافقة مع Vercel ولا تتطلب أسرارًا للمحتوى العام

## مصادر المحتوى

- **Islamic App (رئيسي):** القرآن، النصوص، الترجمات، التفاسير، word-by-word، المصحف SVG، الأذكار، حصن المسلم، الأدعية، ومكتبة الكتب وPDF.
- **AlQuran Cloud (احتياط):** نص السور والبحث عند تعذر المصدر الرئيسي.
- **MP3Quran API v3:** القراء والمصاحف والروايات وسور التلاوة.
- **AlAdhan / Islamic Network:** الصلاة والقبلة والبيانات الهجرية المصاحبة.
- **HadeethEnc:** الحديث ودرجته وشرحه ومراجعه.
- **Fitrahive Dua-Dhikr وasellam/HisnElMuslim:** نسخ محلية احتياطية للأوفلاين. راجع `src/data/devotional/ATTRIBUTION.md`.

توثيق المصدر الرئيسي: <https://docs.islamic.app/>. الخدمة عامة بلا مفاتيح، ويطبّق التطبيق caching طويلًا للمحتوى الثابت ولا يرسل طلبات متكررة بلا داعٍ.

## المتغيرات

لا تحتاج واجهات المحتوى إلى أي مفتاح. المتغير الوحيد الاختياري هو عنوان النشر النهائي:

```env
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

على Vercel يستخدم التطبيق `VERCEL_PROJECT_PRODUCTION_URL` أو `VERCEL_URL` تلقائيًا إن لم تضبطه.

## النشر على Vercel

1. استورد المستودع `AKARI112/TJ` واختر جذر المستودع.
2. اترك إطار العمل Next.js وأمر البناء `npm run build`.
3. لا تضف مفاتيح Quran Foundation؛ لم يعد التطبيق يعتمد عليها.
4. عيّن `NEXT_PUBLIC_APP_URL` فقط عند استخدام نطاق مخصص ثابت.

وضع الضيف كامل ولا يحتاج قاعدة بيانات أو حسابًا. التذكيرات المحلية لا تدّعي العمل بعد إغلاق المتصفح، وWeb Push الخلفي غير مفعّل في هذه النسخة.

## النزاهة والخصوصية

- لا يطبع التطبيق تطبيع البحث على النص القرآني المعروض.
- لا يعرض تفسيرًا أو ترجمة أو مرجع دعاء لم يقدمه المصدر.
- تكرار الدعاء لا ينسب إلى السنة إلا حين يرسل Islamic App قيمة `repeatCount` صراحة.
- تعرض صفحة الكتاب مصادره كما يعيدها Islamic App، ولا تستخدم OCR غير الموثوق بدل النص المحقق.
- المحفوظات والسجل والتذكيرات تبقى محليًا في وضع الضيف، ولا ينزل التطبيق الصوت أو PDF كاملًا تلقائيًا.
