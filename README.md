# ذُو الجَلاَلْ

تطبيق إسلامي عربي أولًا يعمل كرفيق يومي هادئ للقرآن، والمصحف، والتلاوات، والصلاة، والقبلة، والأذكار، والأدعية، وحصن المسلم، والحديث. يحافظ على النصوص الدينية كما يوردها مصدرها، ولا يولّد آيات أو أحاديث أو درجات أو تفاسير.

## ما هو منفّذ فعليًا

- واجهة RTL أصلية، Fustat لكل واجهة التطبيق، داكنة جرافيت افتراضيًا مع وضع فاتح ونظام، وتفضيل دائم.
- beUI v2 من سجل `starc007/ui-components`: Sidebar وBottom Sheet وMorphing Search وTabs وSelect وSwitch وInput ومكوّنات حركة أخرى.
- القرآن في ثلاثة أوضاع: قراءة عصرية مفتوحة، مصحف QCF V2 (mushaf 1)، وتجويد QCF Tajweed V4 (mushaf 19).
- تحميل ديناميكي لخط الصفحة الحالية والمجاورتين فقط، مع صفحات 1–604، السحب المحمول، الانتقال المباشر، وحفظ موضع القراءة في IndexedDB.
- Quran Foundation عبر SDK الرسمي واعتماد server-only مع cache للرمز وإعادة محاولة واحدة بعد 401؛ AlQuran Cloud fallback دلالي لوضع القراءة والبحث.
- تفسير وترجمة كسولان لكل آية من موارد Quran Foundation، ولا يظهر بديل غير موثق عند غياب الاعتماد.
- دليل MP3Quran الكامل، اختيار أي سورة متاحة، صفحات قارئ مستقلة، queue، مشغل عالمي، Media Session، سرعة وصوت وتكرار ومؤقت نوم.
- 97 ذكرًا ودعاءً عربيًا محليًا من Fitrahive مع المراجع والتكرار والبحث والحفظ، وعداد جلسة قابل للاستئناف.
- حصن المسلم كاملًا: 133 بابًا من بيانات `asellam/HisnElMuslim` المرخصة MIT، مع المراجع والصوت حين يتيحه المصدر.
- HadeethEnc: التصنيفات الرئيسية، pagination، التفاصيل، الدرجة كما يقدمها المصدر، الشرح، الفوائد، المراجع، الحفظ والمشاركة.
- الصلاة عبر AlAdhan: الموقع أو المدينة، طرق حساب متعددة، مذهب العصر، 12/24 ساعة، الصلاة الحالية والقادمة والعد التنازلي المحلي وأوقات الليل.
- القبلة: bearing من AlAdhan ثم DeviceOrientation محليًا، إذن iOS، مساعدة المعايرة، وfallback ثابت.
- بحث عام فعلي يجمع السور والآيات والحديث والأذكار والأدعية وحصن المسلم، مع تطبيع عربي للمطابقة فقط.
- محفوظات موحّدة، سجل ذو معنى، متابعة القراءة، مركز تذكيرات بأيام وتفعيل وتعديل وحذف، وإعدادات موسعة.
- Share Composer للآية والحديث والدعاء والذكر: 1:1 و4:5 و9:16، قوالب جرافيت/فاتح/هادئ، حفظ PNG ومشاركة ونسخ؛ ينتظر تحميل الخطوط قبل الالتقاط.
- PWA: manifest، shell cache، cache للمحتوى المقروء، offline fallback، وعدم تنزيل الصوت تلقائيًا.

## التقنية

- Next.js App Router 16.3.3، React 19، TypeScript strict، Tailwind CSS 4
- Server Components افتراضيًا وClient Components لواجهات الجهاز والتفاعل فقط
- Zod لحدود API، Zustand للمشغل، IndexedDB للبيانات المحلية الغنية، LocalStorage للتفضيلات الصغيرة
- Vitest لمنطق القرآن والصلاة والقبلة والتذكيرات والحفظ والتقدم والبحث

## مصادر المحتوى

- Quran Foundation: QCF V2/Tajweed V4، الصفحات، الموارد، التفسير والترجمة والبحث عند تهيئة الاعتماد.
- AlQuran Cloud: السور والنص العثماني ووضع القراءة والبحث المفتوح.
- MP3Quran API v3: القراء والمصاحف والروايات وسور التلاوة.
- AlAdhan / Islamic Network: الصلاة والقبلة وبيانات التاريخ الهجري المصاحبة للمواقيت.
- HadeethEnc: الحديث والدرجة والشرح والفوائد والمراجع.
- Fitrahive Dua-Dhikr وasellam/HisnElMuslim: snapshot محلي للعمل دون اتصال. راجع `src/data/devotional/ATTRIBUTION.md`.

## المتغيرات

انسخ `.env.example` إلى `.env.local`. لا يحتاج وضع القراءة المفتوح والصلاة والقبلة والحديث والتلاوات العامة إلى مفاتيح.

```env
QF_CLIENT_ID=
QF_CLIENT_SECRET=
QF_ENV=production
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

`QF_CLIENT_SECRET` لا يدخل أي bundle للمتصفح. `NEXT_PUBLIC_APP_URL` اختياري محليًا؛ يستخدم التطبيق `VERCEL_PROJECT_PRODUCTION_URL` تلقائيًا في Vercel.

## النشر على Vercel

1. Import المستودع `AKARI112/TJ` في Vercel واختر الجذر الافتراضي للمستودع.
2. إطار العمل Next.js، أمر البناء `npm run build`، ولا يلزم `vercel.json` لهذا البناء.
3. أضف متغيرات Quran Foundation إلى Production وPreview إن أردت QCF والتفسير والترجمة.
4. عيّن `NEXT_PUBLIC_APP_URL` فقط عند استخدام نطاق مخصص ثابت.

التطبيق يبقى صالحًا في وضع الضيف عند غياب قاعدة بيانات أو حساب. تذكيرات IndexedDB لا تدّعي العمل بعد إغلاق المتصفح؛ Web Push الخلفي ليس مفعّلًا في هذه النسخة، ولا توجد مفاتيح Push وهمية في `.env.example`.

## PWA والخصوصية

يحفظ التطبيق الواجهة والصفحات التي زارها المستخدم ويضمّن بيانات الأذكار وحصن المسلم محليًا. لا ينزّل التلاوات تلقائيًا. لا يرسل الموقع الدقيق، أو عناوين التذكير، أو سجل القراءة إلى تحليلات خارجية.

## نزاهة المحتوى

- لا تعدّل نصوص القرآن المعروضة ولا تستخدم تطبيع البحث في العرض.
- لا تعرض درجة حديث إلا من HadeethEnc.
- لا تُنشئ تفسيرًا أو ترجمة أو مرجع دعاء.
- القيمة `لم يذكر المصدر في مجموعة البيانات` ظاهرة عندما يكون الحقل `null` في المصدر بدل ملئه بتخمين.
