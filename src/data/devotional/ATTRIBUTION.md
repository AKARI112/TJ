# Devotional data attribution

- `morning-dhikr.json`, `evening-dhikr.json`, `dhikr-after-salah.json`, `daily-dua.json`, and `selected-dua.json` are local snapshots from [fitrahive/dua-dhikr](https://github.com/fitrahive/dua-dhikr), licensed under MIT. Arabic text, source, and repeat metadata are preserved.
- `hisn.json` is a local snapshot from [asellam/HisnElMuslim](https://github.com/asellam/HisnElMuslim), licensed under MIT. The upstream project states it transcribed and compared the complete Arabic *Hisn al-Muslim* by Saʿid ibn Ali ibn Wahf al-Qahtani.

The application never generates or machine-translates these religious texts. Corrections should be verified against the cited upstream and a printed edition before changing bundled data.
